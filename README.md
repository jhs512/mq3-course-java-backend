# 자바 백엔드 과정

몰입 퀘스트 3의 공개 코스예요.

이 리포는 `course.json`에 수업 구성과 순서만 보관해요.
24개 수업의 본문과 문제는 각 수업 리포에 있어요.
수업은 버전 태그와 SHA-256으로 고정해요.

플레이어에서 기존 gh 계정으로 학습해요.
풀모드와 복습모드 중 자유롭게 선택하세요.
어느 모드든 필수 문제를 통과하면 수업을 완료해요.

진도는 이 리포의 공개 이슈에 남아요.
학습자×수업마다 하나의 이슈를 사용해요.
풀모드 학습과 복습 기록은 따로 보존해요.
수업이 개정돼도 이전 완료 기록은 유지해요.
